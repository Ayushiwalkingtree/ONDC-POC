# File Change Summary

## Modified

- `.env`
  - Converted local placeholders from Seller/BPP wording to Buyer NP/BAP wording.
  - Added registry, subscriber, signing, and verification configuration points.

- `.env.example`
  - Mirrors the Buyer NP local configuration template.

- `app/main.py`
  - Updated OpenAPI title, description, tags, and health metadata for Buyer NP architecture.

- `app/core/config.py`
  - Added `subscriber_id`, `unique_key_id`, `signing_private_key_path`, `ondc_registry_url`, `ondc_registry_timeout_seconds`, and `require_ondc_auth`.
  - Preserved BAP and BPP configuration fields.

- `app/routes/ondc.py`
  - Rebuilt as Buyer NP command routes.
  - Preserved `/search`, `/select`, `/init`, `/confirm`, `/status`.
  - Added `/update`, `/cancel`, `/track`, `/support`.

- `app/callbacks/ondc_callbacks.py`
  - Rebuilt as Buyer NP callback receivers.
  - Preserved `/on_search`, `/on_select`, `/on_init`, `/on_confirm`, `/on_status`.
  - Added `/on_update`, `/on_cancel`, `/on_track`, `/on_support`.
  - Debug transaction endpoints now read through the repository-backed service.

- `app/schemas/ondc.py`
  - Replaced loose optional context fields with strict FIS14 context validation.
  - Added domain, version, timestamp, TTL, action, and required ID validation.
  - Preserved `ONDCRequest` as a compatibility alias.

- `app/schemas/examples.py`
  - Added examples for update, cancel, track, support and matching callbacks.
  - Ensured local examples have distinct `message_id` values for duplicate protection testing.

- `app/services/ondc_service.py`
  - Converted to a compatibility facade over `BuyerNPService`.
  - Retained mock callback builders for local development.

- `app/services/mock_payloads.py`
  - Added local mock builders for `on_update`, `on_cancel`, `on_track`, and `on_support`.

- `app/models/transaction_store.py`
  - Converted to a compatibility shim over the new repository abstraction.

## Added

- `app/schemas/fis14.py`
  - FIS14 command/callback request schema aliases and action literals.

- `app/schemas/transaction.py`
  - Repository-facing transaction event DTO.

- `app/repositories/transaction_repository.py`
  - Repository protocol and duplicate message exception.

- `app/repositories/in_memory_transaction_repository.py`
  - Local repository implementation with duplicate `message_id` protection.

- `app/repositories/__init__.py`
  - Repository exports and default local repository instance.

- `app/services/buyer_np_service.py`
  - Buyer NP orchestration service for commands, callbacks, repository writes, and ACK responses.

- `app/services/protocol_validation.py`
  - Endpoint/action validation for command and callback routes.

- `app/services/registry_service.py`
  - ONDC registry lookup interface and configuration boundary.

- `app/services/signing_service.py`
  - Outbound signing interface and configuration boundary. No fake crypto.

- `app/services/verification_service.py`
  - Inbound verification interface and configuration boundary. No fake crypto.

- `ONDC_BUYER_NP_ARCHITECTURE.md`
  - Buyer NP architecture map and dependency diagram.

- `CLEANUP_PLAN.md`
  - Completed cleanup and remaining cleanup plan.

- `FILE_CHANGE_SUMMARY.md`
  - File-by-file implementation summary.

## Removed

- `app/**/__pycache__/`
  - Generated bytecode only.
